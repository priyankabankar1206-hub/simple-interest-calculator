# Simple Interest Calculator

A lightweight Bash script designed to calculate simple interest based on the principal amount, annual rate of interest, and time period in years.

## Description
Simple interest is calculated using the standard formula:

$$\text{Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$$

This project provides a simple CLI shell script (`simple-interest.sh`) that takes user inputs and outputs the total simple interest and final accrued amount.
